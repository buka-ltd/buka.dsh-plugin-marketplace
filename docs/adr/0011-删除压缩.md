# ADR 0011：删除压缩，一任务一会话

- 状态：已采纳（2026-11-12）
- 影响面：robots 的会话服务、workflows 的任务执行与恢复

## 背景

旧模型里同一个机器人在一次运行中复用一个会话，重入前调用 compact，避免历史无限膨胀。新模型里任务是最小执行单元，任务之间靠依赖数据传上下文，会话复用不再成立。

## 决定

1. **一个任务一条新会话。** 不复用上一条任务的会话；任务之间通过 payload / 依赖结果 / 附件传上下文。
2. **删除压缩。** 删除 `ctx.compaction.compactNow` 与所有 `compactFirst` 路径；恢复只续接同一会话，不压缩。
3. **任务上下文由引擎组装。** 岗位说明 + 任务类型说明 + 渲染后的 payload + 依赖结果摘要 + 可见附件 + 产出契约；大内容用只读工具 / 附件读取。
4. **阻塞的 `startSession` 删除候选。** workflows 只用非阻塞的 `dispatchSession` / `openSession`。
5. **plan 模式保留。** 任务类型可以声明 `mode: "plan"`，进入执行前对目标 agent 执行 `/plan`。

## 后果

- robots 服务更薄：会话创建 / resume / 事件观测 / 观测句柄，不再管压缩与结果追问。
- 结果契约与校验移到 workflows 的 `buka_task_complete`。
- 恢复逻辑不再依赖 compaction 服务；桌面 profile 禁用压缩也可以正常跑。
