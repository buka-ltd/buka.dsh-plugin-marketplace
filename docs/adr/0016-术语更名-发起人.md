# ADR 0016：术语更名「启动者」→「发起人」

- 状态：已采纳（2026-11-13）；取代 ADR 0005 / 0008 / 0012 中的「启动者」命名
- 影响面：术语表、workflows 的文案与文档、工作流定义版本

## 背景

「启动者」把动作「启动」直接加「者」当人用，读起来更像「启动器 / 启动按钮」，而不是一个做决定的人；而且这个名字只覆盖「谁开始」，没覆盖这个角色的另一半职责——结束任务把最终交付物交回给同一个人。

ADR 0008 写背景时的原话是「谁发起这次工作、结果回到谁」：本来要说的就是「发起」。

## 决定

1. **角色名改为「发起人」。** 定义不变：启动作业的一方，人（页面启动）或会话（`/job` 启动），是开始 / 结束任务的执行者。代码标识符维持 `starter`（和「发起人」正好对上），不改字段与 API。
2. **只改指人的名词。**「启动作业」「启动任务」「页面启动」这些动作、节点与任务名保留——被抱怨的是把「启动」当成人，不是「启动」这个词本身。
3. **词典、界面文案、文档、测试断言与代码注释同步改。** ADR 0005 / 0008 / 0012 的正文按历史写法保留，只在状态行标注。
4. **工作流定义升一个版本。**「小工具交付」的通道 label「交回启动者」改为「交回发起人」，任务说明同步；已有作业钉在旧版本，不受影响。

## 后果

- 纯文案改动，没有存储结构变化；旧作业与旧工作流版本继续用旧措辞。
- `starter`、`TaskRecord`、路由与工具名都不变，跨插件引用不受影响。
