# ADR 0012：附件按数据流授权

- 状态：已采纳（2026-11-12）
- 影响面：workflows 的附件、任务上下文、页面附件库

## 背景

旧模型的附件散落在每次执行的目录里，没有来源元数据，也没有权限；任意节点都能读运行目录里的附件。

## 决定

1. **每个作业一个附件库。** 每条附件必须记录来源任务 / 岗位、创建者、创建时间、名称、大小、mime、sha256、描述。
2. **可见性按数据流。** 可见主体：产出附件的任务、直接或传递依赖它的任务、启动者、作业看板页面（人）。不相关分支的任务 / 岗位不能列出、检索或读取。
3. **任务上下文只列可见附件。** 上下文里只列「依赖任务产出且对当前任务可见」的附件；完整内容按 id 读取。
4. **检索按可见范围过滤。** 作业附件库页面展示全部附件与来源任务；机器人任务的检索只返回可见集合。
5. **存储分离。** 附件文件放插件作业目录（沿用安全校验、去重、限额）；元数据进 `storageDomain`。

## 后果

- 附件必须绑定来源任务；没有来源的附件不允许入库。
- 任务工具要按任务 id 计算可见集合；越权读取直接拒绝。
- 页面新增作业级附件库与检索。
