# Buka Skills

Adds a Skills page to the sidebar with two tabs: Installed lists the skills installed globally for every DSH session and uninstalls each one the right way (through npx skills, or by deleting a manually installed directory); Saved keeps a personal list of npx skills sources (owner/repo, GitHub/GitLab links, any git URL, absolute local paths, and package names — packages can be saved but not expanded) entered through a Save dialog opened from the button next to Refresh, opens a repo from its title when the source has a web address, deletes entries with a delete button styled like the uninstall action, probes each listable saved source (GitHub, any git remote, or a local path) and labels it as an npx skills repository, a Claude Code marketplace, or unavailable, and expands the usable ones into a cached skills tree grouped by plugin for marketplaces, and installs any single skill from that tree into the global skills directory with one click (through npx skills add -g; an already-installed skill shows a disabled Installed button instead); git remotes are shallow-cloned into a cache under the DSH home and local paths are scanned in place, and it exposes the saved repositories, their skills and marketplace plugins to other plugins through the ctx.bukaSkills Host service.
